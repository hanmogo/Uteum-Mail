2026-10-01 사용자 선택으로 **Spring Boot와 Python/FastAPI 분리, Next.js·React·TypeScript 웹, PostgreSQL 운영 DB**를 확정했습니다. Temurin Java 25 LTS·Boot 4.1.x, Python 3.14.x·FastAPI 0.142.x·Next.js 16.x·Node.js 24 LTS를 채택하고, Java 25 호환 문제가 확인되면 21 LTS를 사용합니다. PostgreSQL 18.x 검증·로컬 개발·무료 관리형 DB 우선 비교, SQS Standard·VM·Docker·pgvector 제한 검증·S3·CloudWatch·필요 구간의 OpenTelemetry와 초기 검증·복구 목표도 승인됐습니다. 사업자·예산·검색 범위·임베딩 모델 등 세부 선택은 남아 있습니다. 시험 조건·요금 정책과 앱·고도화의 세부 결정은 보류하고 기획서 정리와 프로토타입을 먼저 진행합니다.

2026-10-03에는 **C안: 기존 Luna·Sol 운영 경로 → Jev 결과 미반영 평가 → 검증 범위의 제한 적용**을 확정했습니다. 첫 프로토타입은 가상 데이터와 정해진 응답으로 전체 핵심 여정의 화면·상호작용을 확인하며, 밝고 간결한 업무형 UI와 Tailwind CSS·shadcn/ui를 사용합니다. 2026-10-04 기준 `apps/web`에 S1~S9 화면과 가상 상호작용을 구현하고 기술 검증을 마쳤습니다. 사용자 화면 검토와 이후 메일·서버·AI 연결은 후속 작업입니다. 범위·순서는 14·15번, 실제 검증 결과는 16번 문서를 따릅니다.

## 웹 프로토타입 실행

Node.js 24 LTS에서 실행합니다.

```bash
cd apps/web
npm ci
npm run dev
```

개발 화면: [http://127.0.0.1:3000](http://127.0.0.1:3000). 프로덕션 실행은 `npm run build` 후 `npm run start -- --port 3001`을 사용합니다.

- 가상 계정·메일만 사용하며, API 키나 외부 서비스 설정이 필요하지 않습니다.
- 첫 실행은 준비된 자료로 시작합니다. 가상 계정 추가 화면의 **처음부터 체험**으로 시작 설정을 확인할 수 있습니다.
- **체험 설정**에서 분석 실패·연결 만료·수신 해제 부분 실패·발송 미확인을 재현할 수 있습니다.
- 편집 내용은 현재 브라우저와 주소의 localStorage에 저장됩니다. 데모 초기화로 원본을 복원합니다.
- 자세한 명령과 구조는 [프런트엔드 안내](apps/web/README.md)를 참조합니다.
