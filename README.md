# Uteum-Mail

통합 이메일 AI 비서 프로젝트입니다. 데스크톱·모바일 웹을 먼저 진행하고, 별도 앱은 웹 결과를 확인한 뒤 검토합니다.

## 최신 기획과 기술 검토

| 문서 | 내용 |
| --- | --- |
| [웹앱 기획서 v1.6](docs/07-웹앱-기획서-v1.6.md) | 2026-09-30 기술 스택 논의, 짧은 요청 UX, 권장 시스템 구성, 작업 복구, 후속 앱 준비와 검증 기준 반영 |
| [기술 스택 선택 비교 보고서 v1.0](docs/06-기술-스택-선택-비교-보고서-v1.0.md) | Spring 단일·분리 구성, Python·TypeScript·Go·C# 대안, 성능·유지보수·통신·운영·앱 확장 비교 |

현재 권장 기본안은 React/Next.js 웹, Spring Boot 공용 백엔드, Python AI 영역과 FastAPI, PostgreSQL입니다. 보고서와 기획서는 사용자 확인 사항·권장안·미확정 사항을 구분하며, 최종 스택 확정이나 구현·성능 검증 완료를 뜻하지 않습니다.
