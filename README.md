2026-10-01 사용자 선택으로 **Spring Boot와 Python/FastAPI 분리, Next.js·React·TypeScript 웹, PostgreSQL 운영 DB**를 확정했습니다. Temurin Java 25 LTS·Boot 4.1.x, Python 3.14.x·FastAPI 0.142.x·Next.js 16.x·Node.js 24 LTS를 채택하고, Java 25 호환 문제가 확인되면 21 LTS를 사용합니다. PostgreSQL 18.x 검증·로컬 개발·무료 관리형 DB 우선 비교, SQS Standard·VM·Docker·pgvector 제한 검증·S3·CloudWatch·필요 구간의 OpenTelemetry와 초기 검증·복구 목표도 승인됐습니다. 사업자·예산·과거 색인 기간·물량·임베딩 모델 등 세부 선택은 남아 있습니다. 시험 조건·요금 정책과 앱·고도화의 세부 결정은 보류하고 기획서 정리와 프로토타입을 먼저 진행합니다.

2026-10-03에는 **C안: 기존 Luna·Sol 운영 경로 → Jev 결과 미반영 평가 → 검증 범위의 제한 적용**을 확정했습니다. 첫 프로토타입은 가상 데이터와 정해진 응답으로 전체 핵심 여정의 화면·상호작용을 확인하며, 밝고 간결한 업무형 UI와 Tailwind CSS·shadcn/ui를 사용합니다. 2026-10-04 기준 `apps/web`에 S1~S9 화면과 가상 상호작용을 구현하고 기술 검증을 마쳤습니다. 사용자 화면 검토와 이후 메일·서버·AI 연결은 후속 작업입니다. 범위·순서는 14·15번, 실제 검증 결과는 16번 문서를 따릅니다.

2026-10-29에는 보유 OpenAI API 크레딧을 고려해 **GPT Decisions API를 먼저 검증하고 기준을 통과한 범위를 초기 운영에 사용하며, Jev는 비교 후보로 유지**하기로 확정했습니다. Luna·Sol 기준선과 결과 미반영 평가 원칙을 유지하며, 기존 품질·안전·지연·비용 기준과 사전에 정한 기능별 수용 기준으로 적용 범위를 확인합니다. 크레딧 조건·실제 사용량·정상 비용은 별도 관찰합니다. [기획서 9.5](docs/07-웹앱-기획서-v1.6.md#95-채택한-모델-도입-순서와-상세-에이전트-설계)에 현재 순서를 반영했습니다.

2026-10-13에는 **직접 조회·키워드 검색을 기본으로 하는 RAG와 관련 과거 메일 탐색의 임베딩 보강** 방향을 승인했습니다. 초기에는 분석이 허용된 제목·본문을 pgvector로 제한 검증합니다. [스택 보고서 9.1](docs/06-기술-스택-선택-비교-보고서-v1.0.md#91-pgvector-검색과-임베딩-사용-방식)에 적용 기능·초기 범위·자료 처리·검증 순서를, [기획서 13.2](docs/07-웹앱-기획서-v1.6.md#132-기술-구성과-앱-확장의-검증-기준)에 품질·비용·지연·기본 메일 부하의 검증 항목을 정리했습니다. 실제 임베딩 연결·평가·운영 적용은 후속 단계입니다.

2026-10-29 후속 추천안 승인으로 작업·VM 배치·보관·복구 원칙, 시작 설정·자료 처리의 검토 방향, 월간 홈 캘린더, 마스킹 비교·적용 원칙을 관련 문서에 반영했습니다. 후속 결정 목록에는 사업자·수치·구체 문구 등 남은 선택만 둡니다. [Neon·Supabase 비교](docs/08-Java-버전과-AWS-비용-검토-v1.0.md#45-neon과-supabase의-차이와-초기-선택안)와 [초기 임베딩 필요성 분석](docs/06-기술-스택-선택-비교-보고서-v1.0.md#916-초기-개발에서-임베딩이-꼭-필요한가)을 추가했습니다. RAG·GPT Decisions 모두 검색용 임베딩 없이 시작할 수 있으며, 첫 실제 구현에서 임베딩을 미루는 안은 도입 시점에 대한 새 추천으로 사용자 선택 전입니다.

2026-10-29 초기 DB 개발 환경은 **로컬 PostgreSQL 18.x**로 확정했습니다. 공유 DB 호스팅·요금제·예산은 외부 배포가 필요해질 때 선택합니다. Neon·Supabase·RDS는 그때의 비교 후보로 유지하며, 현재 가상 화면 프로토타입은 기존 자료·상태 방식으로 동작합니다. 이 결정은 DB 설치·서버 연결 완료 기록과 구분합니다.

## 웹 프로토타입 실행

Node.js 24 LTS에서 실행합니다.

```bash
cd apps/web
npm ci
npm run dev
```

개발 화면: [http://127.0.0.1:3000](http://127.0.0.1:3000). 프로덕션 실행은 `npm run build` 후 `npm run start -- --port 3001`을 사용합니다.

- 가상 계정·메일만 사용하며, API 키나 외부 서비스 설정이 필요하지 않습니다.
- 첫 실행은 준비된 자료로 시작합니다. 가상 계정 추가 화면의 **처음부터 체험**으로 시작 설정을 확인할 수 있습니다.
- **체험 설정**에서 분석 실패·연결 만료·수신 해제 부분 실패·발송 미확인을 재현할 수 있습니다.
- 편집 내용은 현재 브라우저와 주소의 localStorage에 저장됩니다. 데모 초기화로 원본을 복원합니다.
- 자세한 명령과 구조는 [프런트엔드 안내](apps/web/README.md)를 참조합니다.
